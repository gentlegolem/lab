# Gentle Golem Lab

The Lab is where Gentle Golem, a small game-dev tools and agentic AI studio in Quebec, writes up what it tries and
what it measures. Each subject below has a status and the date it was last checked. Results come with their sample
size and limits; estimates are marked (est.).

A Lab page on the Gentle Golem website will link here (not live yet).

## Subjects

| Subject | Status | Checked |
|---|---|---|
| Loft mesh editor: building game meshes from a few cross-sections | Working | checked 2026-11-05 |
| Picture → map: turning a picture into a playable map layout | Early results | checked 2026-11-05 |
| Creature pipeline: from concept to an animated game creature | Testing | checked 2026-11-05 |
| AI safety / red-team testing: how agents' claims and guardrails hold up | Measuring | checked 2026-11-05 |
| AI model usage: an architect agent vs none, which model for which task ([agent-study](agent-study/)) | Early results | checked 2026-11-05 |
| Token optimization: task budgets and context size ([agent-study](agent-study/)) | Early results | checked 2026-11-05 |
| Thermal imaging: what thermal pictures can and can't show | Reading | checked 2026-11-05 |
| Game ideas used in real life: game mechanics applied to everyday tools | Idea | checked 2026-11-05 |

**Statuses:** Working = in use · Testing = built, being checked · Early results = first numbers, small n ·
Measuring = data being collected · Reading = background research · Idea = not started.
